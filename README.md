## 📂 Featured Projects

### 🔷 [NVIDIA Stock Price Predictor](https://github.com/emirokay/stock-price-predictor)
Ensemble of 4 ML models (XGBoost, LightGBM, Ridge, ExtraTrees) + anchor to forecast 5-day NVDA closing prices.

- **67 financial features**: lag returns, momentum, volatility, MACD, RSI-14, ADX/DMI, Bollinger Bands, peer returns, VIX, calendar signals
- Walk-forward purged cross-validation with embargo to prevent leakage
- Hyperparameter tuning via Optuna (20+ parameters)
- Self-calibrated 80% confidence intervals, Theil's U, Sharpe ratio evaluation

### 🔷 [F1 Race Predictor](https://github.com/emirokay/f1-race-predictor)
XGBRanker predicting Formula 1 finishing order using a learning-to-rank approach.

- `rank:pairwise` objective optimized for ranking accuracy
- 4 years of F1 data extracted via FastF1 API
- Features: qualifying gaps, sprint results, car strength, tire degradation rates
- Leave-One-Year-Out cross-validation on street circuits

### 🔷 [Big Data Fraud Detection](https://github.com/emirokay/Fraud_Detection)
PySpark/Databricks fraud detection pipeline on an imbalanced dataset (0.17% fraud rate).

- Improved fraud detection recall from **78% → 85%** via under-sampling
- Benchmarked 3 classifier models
